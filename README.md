# Müziklerim

Reklamsız, sade bir müzik uygulaması (PWA). Telefona "Ana ekrana ekle" ile kurulur.

- **Keşfet:** haftanın trendleri, türler, öne çıkan listeler, yeni sesler
- **Ara:** şarkı, sanatçı ve liste arama
- **Anlık dinleme** ve **indirip internetsiz dinleme**
- **Kitaplığım:** indirilenler, beğenilenler, kendi çalma listelerin, telefondan mp3 ekleme
- Kilit ekranı kontrolleri, uyku zamanlayıcı, karışık / tekrar

Müzik kataloğu: [Audius](https://audius.co) açık API'si (sanatçıların ücretsiz paylaşıma açtığı şarkılar).
Kurulum adımı yok; statik dosyalardan oluşur.
