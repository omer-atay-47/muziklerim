# Müziklerim

Reklamsız, **tamamen internetsiz** müzik ve klip çalar (PWA). Telefona "Ana ekrana ekle" ile kurulur.

- **Şarkı Ekle** → dosya seçici açılır → seçilen şarkı hemen çalar
- **Klipler:** telefondaki video dosyaları (mp4, mov, webm…) görüntüsüyle birlikte oynar; tam ekran desteği
- Ses dosyaları: mp3, m4a, aac, wav, flac, ogg/opus
- MP3 içindeki şarkı adı, sanatçı ve kapak resmi otomatik okunur (Türkçe karakterler dahil); videolardan kapak karesi alınır
- Tüm şarkılar, Favoriler, Listelerim; arama ve sıralama
- Kilit ekranı kontrolleri, uyku zamanlayıcı, karışık / tekrar, kaldığı yerden devam

İnternet kullanılmaz: şarkılar ve klipler telefonun içinde (IndexedDB) saklanır, hiçbir yere gönderilmez.
